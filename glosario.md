# Glosario — un término por concepto

Texto de cara al usuario. Trato: **tú** (español de Perú). No usar voseo
("podés", "tenés", "ofrecés"…).

| Concepto | Término único | No decir |
|---|---|---|
| La app / marca | **Necesito** | — |
| Lo que se publica | **necesidad** ("una necesidad") | "un necesito", "solicitud", "pedido", "aviso" |
| Publicar una necesidad | **publicar** | "postear", "crear", "subir" |
| Quien publica | **comprador** | "creador", "publicador", "solicitante" |
| Quien responde con precio | **vendedor** | "postor", "oferente", "proveedor" |
| La respuesta con precio | **oferta** | "puja", "postura", "propuesta" |
| Hacer una oferta | **ofertar** | "pujar", "postular" |
| El vendedor que el comprador selecciona | **elegido** | "ganador", "seleccionado" |
| Seleccionar al elegido | **elegir** | "aceptar", "adjudicar" |
| Terminar la necesidad aceptando al elegido | **cerrar** ("cerrar la necesidad") | "finalizar", "adjudicar" |
| El comprador retira su necesidad sin elegir | **cancelar** | "eliminar", "borrar" |
| El vendedor retira su propia oferta | **retirar** ("retirar la oferta") | "cancelar la oferta" |
| El vendedor marca que entregó | **entregar** / "marcar como entregado" | "despachar", "completar" |
| El comprador aprueba la entrega | **confirmar** | "verificar", "validar" |
| El comprador no aprueba | **reportar un problema** | "disputar", "reclamar", "desacuerdo" |
| Estado mientras la plataforma revisa | **en revisión** | "en disputa" |
| Fotos que aportan las partes | **evidencia** | "pruebas", "respaldo" |
| Puntuar al elegido (estrellas + etiquetas) | **calificar** | "reseñar", "valorar", "puntuar" |
| El resultado de calificar | **calificación** | "reseña", "valoración" |
| Marcar una necesidad para después | **guardar** → "guardada" | "favorito" |
| Zona geográfica | **distrito** | "zona", "barrio", "ubicación" |
| Cómo actúa el usuario ahora (habilita/bloquea acciones) | **modo** (Comprador / Vendedor) | "rol", "vista", "perfil" |
| Qué es el usuario | **Persona / Negocio** | "tipo", "categoría" |
| Frase corta bajo el nombre | **título del perfil** | "rol público", "cargo", "bio" |
| Texto largo del perfil | **descripción** | "acerca de", "sobre mí" |
| Mensajes + ofertas dentro de una necesidad | **hilo** | "chat público", "comentarios" |
| Conversación privada 1‑a‑1 | **chat** ("chat privado") | "DM", "mensaje directo" |
| Aviso de actividad | **notificación** | "alerta" |
| Tipo de necesidad | **Producto / Servicio** | — |

## Rótulos fijos ya aplicados

- Perfil, secciones: "Lo que publicaste" · "Tus ofertas activas" ·
  "Esperando confirmación de entrega" · "Trabajos que atendiste" · "Guardadas".
- Perfil, stats: "Tratos cerrados" · "Calificación" · "Calificaciones".
